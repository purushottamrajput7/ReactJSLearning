# parcel - What it does ?

- Dev Build
- Local Server
- HMR (Hot Module Replacement) - Updating our modules on server automatically if state or contnet changes or anything happens to app , without refreshing the browser.
- File Watching Algorithm - Written in C++
- Caching - Faster Builds
- Image Optimisation
- Minification -
- Bundling - Bundles all the files to make it one or few files to send to production
- Compressing -
- Consitent Hashing - chnaging the file URLs everytime the state or any content changes.
- Code Splitting - Creating small chunks
- Tree Shaking - Update dom tree and removes unused code.
- Diagnosting - Proper error handling
- Diffrential Bundling - To Supports older version browsers
- Creates different dev and production bundles.
- Can host your apps on HTTPs server (npx parcel index.html --https).
